# QuantumLab

**Виртуальная лаборатория квантовых вычислений** — учебный симулятор квантовых схем
на один или два кубита для начинающих.

Все расчёты выполняются на классическом компьютере (моделирование вектора состояния
средствами NumPy). Приложение не подключается к реальному квантовому оборудованию.

## Возможности

- Конструктор схем: гейты `X`, `H`, `Z`, `RY(θ)` (угол в градусах), `CNOT` с любым
  управляющим кубитом; до 20 операций; удаление последней операции и очистка схемы.
- SVG-диаграмма схемы, построенная по реальному списку операций, и пояснения на русском языке.
- Конечное состояние: амплитуды (Re, Im), вероятности |α|², проверка нормировки,
  пошаговая эволюция состояния.
- Моделирование 10…10 000 измерений с заданным seed и сравнение частот
  с теоретическими вероятностями на графике.
- Сфера Блоха для одного кубита.
- Четыре учебных эксперимента: инверсия бита, суперпозиция, интерференция, состояние Белла.
- Воспроизводимое исследование «Число измерений и отклонение частот» (TVD, seed 1…30).
- Экспорт: схема в JSON (и обратная загрузка), результаты в CSV (UTF-8 с BOM),
  самостоятельный HTML-отчёт.

## Соглашение о базисе

Метки `|q0 q1⟩`: `q0` — левый бит, `q1` — правый. Порядок базиса:
`|00⟩, |01⟩, |10⟩, |11⟩` (индекс = 2·q0 + q1). Однокубитный гейт на `q0` — это `U ⊗ I`,
на `q1` — `I ⊗ U`.

## Установка и запуск

Требуется Python 3.11 или новее.

### Windows (PowerShell)

```powershell
cd QuantumLab
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Если PowerShell запрещает запуск скрипта активации, выполните один раз
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или используйте `cmd`:
`.venv\Scripts\activate.bat`.

### macOS / Linux

```bash
cd QuantumLab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501.

### Тесты

```bash
python -m pytest -q
```

## Структура

| Файл | Назначение |

| `quantum.py` | Векторы состояний, матрицы гейтов, измерения, TVD, сфера Блоха |

| `reporting.py` | Экспорт JSON, CSV и HTML |
| `app.py` | Интерфейс Streamlit |
| `tests/` | Тесты pytest |

## Методика исследования

Гипотеза: «Интерактивная модель может помочь учащимся исследовать связь между квантовыми
операциями и вероятностями измерения».

Вычислительный эксперимент: для схемы `H` при N = 10, 100, 1000, 10 000 и seed 1…30
вычисляется расстояние полной вариации `TVD = 0,5 · Σ|fᵢ − pᵢ|`. Для каждого seed
генерируется одна серия из 10 000 измерений, частоты берутся по её первым N исходам.
Результаты можно скачать в CSV.

## Ограничения

- Поддерживаются только один или два кубита.
- Шум, декогеренция и аппаратные ошибки не моделируются.
- Вычисления выполняются на классическом оборудовании.
- Образовательная эффективность требует отдельного исследования с участием учащихся.
